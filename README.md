# ศัพท์ 5000: เว็บแอปเรียนคำศัพท์ภาษาอังกฤษตามระดับ CEFR

เว็บแอปสำหรับเรียนคำศัพท์ภาษาอังกฤษ 5,000 คำ แบ่งเป็น 5 ระดับ (A1–C1) มีแฟลชการ์ดที่ใช้ระบบทบทวนเป็นระยะ (spaced repetition) แบบทดสอบความหมายภาษาไทย และการฝึกอ่านออกเสียงคำและประโยคตาม tense ที่บอกว่าอ่านถูกหรือผิดทีละคำ ความก้าวหน้าทั้งหมดบันทึกไว้ในเบราว์เซอร์ของผู้เรียน ไม่ต้องล็อกอิน และไม่มีเซิร์ฟเวอร์

## คุณสมบัติ

### ฝึกอ่านออกเสียง

- **ฝึกอ่านคำ (5,000 คำ)**: ทุกคำมีคำอ่าน IPA (สำเนียงอเมริกัน) คำอ่านภาษาไทยโดยประมาณ พยางค์พร้อมบอกพยางค์ที่ต้องลงเสียงหนัก และตัวอักษรสำหรับสะกด กด "สะกดทีละตัว" เพื่อฟังการสะกดพร้อมไฮไลต์ตัวอักษร มีปุ่มฟังเสียงปกติและฟังช้า
- **ฝึกอ่านประโยคตาม tense**: 150 ประโยค แบ่งตามระดับ A1–C1 และตาม tense (A1 เริ่มจาก 4 tense จนถึงครบ 12 tense ที่ C1) แต่ละ tense มีโครงสร้าง วิธีใช้ และคำบ่งชี้ คำสำคัญที่ควรเน้นเสียงมีขีดเส้นใต้ แตะคำเพื่อฟังทีละคำได้
- **บอกว่าอ่านถูกหรือผิดทีละคำ**: กด "กดแล้วอ่านออกเสียง" ระบบจะฟังผ่านไมโครโฟน (Web Speech API) แล้วเทียบกับประโยคทีละคำ บอกว่าคำไหน ✓ ถูก, ~ เกือบถูก, ✗ ผิด (พร้อมบอกว่าได้ยินเป็นคำอะไร) หรือ – ไม่ได้อ่าน และให้คะแนน 0–100 ใช้ได้บน Chrome, Edge และ Safari ส่วนเบราว์เซอร์ที่ไม่รองรับ (เช่น Firefox) จะให้ผู้เรียนประเมินตัวเองแทน
- **คำที่ต้องฝึก**: คำที่อ่านผิดจะถูกเก็บไว้ให้ฝึกซ้ำ และหายไปเมื่ออ่านถูก 2 ครั้ง
- **สถิติรายวัน**: จำนวนครั้งที่ฝึกเทียบเป้าหมายต่อวัน คะแนนเฉลี่ย เปอร์เซ็นต์คำที่อ่านถูก วันที่ฝึกติดต่อกัน กราฟ 14 วันล่าสุด และคะแนนเฉลี่ยแยกตามระดับ
- เลือกเสียงอ่านสำเนียง US หรือ UK ได้

### เข้าสู่ระบบและรายงานสำหรับครู

- ผู้เรียนเข้าใช้ด้วย **ชื่อ-นามสกุล** และเลือก **ศกร.ระดับตำบล** (15 ตำบล) ไม่ต้องมีรหัสผ่าน
- หลายคนใช้เครื่องเดียวกันได้ ความก้าวหน้าและสถิติแยกเป็นรายคน กด "ออกจากระบบ" เพื่อสลับผู้ใช้
- หน้า **รายงานสถิติผู้เรียน** (`#/report`, มีลิงก์ที่หน้าเข้าสู่ระบบและหน้าสถิติ) แสดงสรุปตาม ศกร. ตารางรายบุคคล (เรียงและค้นหาได้ ดาวน์โหลดเป็น CSV) และหน้ารายบุคคล: กราฟรายวัน คะแนนตามระดับ คำที่อ่านผิดบ่อย และประวัติการฝึกล่าสุด
- ถ้ายังไม่ได้เชื่อม Google Sheets รายงานจะแสดงเฉพาะผู้ใช้บนเครื่องนั้น เมื่อเชื่อมแล้วจะรวมทุกคนจากทุกเครื่อง

> การตรวจการออกเสียงอาศัยระบบรู้จำเสียงพูดของเบราว์เซอร์ จึงตรวจได้ระดับ "คำ" (ระบบได้ยินเป็นคำที่ถูกหรือไม่) ไม่ได้วิเคราะห์ทีละเสียงหรือการเน้นเสียง ส่วนคำอ่านภาษาไทยสร้างอัตโนมัติจาก IPA จึงเป็นเพียงคำอ่านโดยประมาณ

### คำศัพท์

- **แฟลชการ์ด**: แตะการ์ดเพื่อดูความหมาย แล้วเลือกว่า "ยังไม่จำ / จำได้ / ง่ายมาก" ระบบจะกำหนดวันทบทวนครั้งต่อไปให้เอง (ทบทวนเร็วขึ้นถ้าลืม และเว้นนานขึ้นถ้าจำได้)
- **แบบทดสอบ 4 ตัวเลือก**: ทำได้ทั้งแบบอังกฤษ→ไทย และไทย→อังกฤษ เลือกจำนวน 10–50 ข้อ และเลือกคำจากทั้งระดับ จากคำที่เรียนแล้ว หรือจากคำที่ยังจำไม่แม่น คำที่ตอบผิดจะกลับมาให้ทบทวนในแฟลชการ์ด
- **ฟังเสียงอ่าน**: ใช้เสียงสังเคราะห์ของเบราว์เซอร์ (Web Speech API) จึงไม่ต้องใช้ไฟล์เสียง
- **รายการคำและค้นหา**: ค้นหาได้ทั้งคำอังกฤษและคำไทย และกรองตามสถานะการเรียน
- **สถิติ**: ความก้าวหน้าแต่ละระดับ จำนวนวันที่เรียนติดต่อกัน และผลแบบทดสอบย้อนหลัง
- **สำรองและนำเข้าข้อมูล**: ดาวน์โหลดความก้าวหน้าเป็นไฟล์ JSON เพื่อย้ายไปเครื่องอื่นได้
- ใช้บนมือถือได้ รองรับโหมดมืด และมีคีย์ลัดบนคอมพิวเตอร์ (Space = พลิกการ์ด, 1/2/3 = ให้คะแนน, 1–4 = เลือกคำตอบ, Enter = ข้อต่อไป, S = ฟังเสียง)

## ที่มาของคำศัพท์

| ระดับ | จำนวนคำ | ที่มา |
|---|---:|---|
| A1 | 898 | The Oxford 3000™ by CEFR level |
| A2 | 867 | The Oxford 3000™ by CEFR level |
| B1 | 806 | The Oxford 3000™ by CEFR level |
| B2 | 726 | The Oxford 3000™ by CEFR level |
| C1 | 1,703 | คัดเลือกเพิ่มเติม (คำศัพท์ระดับสูง/วิชาการ) |
| **รวม** | **5,000** | |

- บางคำอยู่ในหลายระดับเพราะมีความหมายหรือชนิดคำต่างกัน เช่น *like* (A1: ชอบ, เหมือน; B1: สิ่งที่ชอบ) ในข้อมูลนี้ถือเป็นการ์ดแยกกัน
- ความหมายภาษาไทยทั้งหมดเขียนขึ้นใหม่สำหรับแอปนี้ **ควรให้ครูตรวจทานก่อนนำไปใช้สอนจริง** โดยเฉพาะระดับ B2–C1
- ระดับของคำ C1 เป็นการประเมินของผู้จัดทำ ไม่ได้มาจากรายการทางการของ Oxford

## แก้ไขหรือเพิ่มคำศัพท์

คำศัพท์ทั้งหมดอยู่ในไฟล์เดียวคือ [`data/words.tsv`](data/words.tsv) ซึ่งเปิดแก้ใน Excel หรือ Google Sheets ได้ แต่ละบรรทัดมี 4 คอลัมน์ คั่นด้วย Tab:

```
level	word	pos	thai
A1	apple	n.	แอปเปิล
```

แก้ไขเสร็จแล้วตรวจความถูกต้องด้วยคำสั่ง `npm run check-data`

ประโยคสำหรับฝึกอ่านอยู่ใน [`data/sentences.tsv`](data/sentences.tsv) (คอลัมน์ `level`, `tense`, `en`, `thai`) ให้เขียนตัวเลขเป็นคำ (ten ไม่ใช่ 10) เพื่อให้ตรวจการอ่านได้

คำอ่าน IPA และคำอ่านไทยอยู่ใน [`data/pron.tsv`](data/pron.tsv) ซึ่งสร้างจาก [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) (สัญญาอนุญาตแบบ BSD) หลังเพิ่มคำหรือประโยคใหม่ ให้สร้างไฟล์นี้ใหม่:

```bash
curl -LO https://raw.githubusercontent.com/cmusphinx/cmudict/master/cmudict.dict
node scripts/build-pron.mjs cmudict.dict
```

ความก้าวหน้าของผู้เรียนผูกกับ `ระดับ:คำ` ดังนั้นการแก้ความหมายจะไม่ทำให้ความก้าวหน้าหาย แต่ถ้าเปลี่ยนตัวสะกดของคำหรือย้ายคำไปอยู่ระดับอื่น ความก้าวหน้าของคำนั้นจะเริ่มใหม่

## เก็บสถิติผู้เรียนลง Google Sheets

แอปไม่มีเซิร์ฟเวอร์ของตัวเอง จึงใช้ Google Sheet ของหน่วยงานเป็นที่เก็บข้อมูล (ฟรี ไม่ต้องใช้ API key) ทุกครั้งที่ผู้เรียนเข้าใช้ ฝึกอ่าน หรือทำแบบทดสอบ แอปจะส่งข้อมูล 1 แถวเข้า Sheet ถ้าไม่มีอินเทอร์เน็ตจะเก็บไว้ในเครื่องแล้วส่งให้ทีหลัง

1. สร้าง Google Sheet ใหม่ (ใช้บัญชี Google ของหน่วยงาน)
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. แก้บรรทัด `const REPORT_PIN = 'CHANGE-ME';` เป็นรหัสที่ครูจะใช้เปิดหน้ารายงาน แล้วกดบันทึก
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เลือกประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. กด **ทำให้ใช้งานได้** อนุญาตสิทธิ์ แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
6. นำ URL ไปใส่ในไฟล์ [`src/config.ts`](src/config.ts) (แทน URL เดิม) แล้ว push ขึ้น `main` เว็บจะ deploy ใหม่เอง
7. ทดสอบ: เข้าใช้แอปและอ่านออกเสียง 1 ครั้ง ควรเห็นแถวใหม่ในแท็บ `Attempts` ของ Sheet และเปิด `#/report` ด้วยรหัสจากข้อ 3 ได้

ถ้าแก้ `Code.gs` ภายหลัง ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** ทุกครั้ง ไม่อย่างนั้น URL เดิมจะยังใช้โค้ดเก่า

ข้อมูลที่เก็บ: ชื่อ, ศกร., เวลา, ประเภท (เข้าใช้/คำ/ประโยค/แบบทดสอบ), ระดับ, tense, ข้อความที่อ่าน, คะแนน, จำนวนคำที่อ่านถูก และคำที่อ่านผิด ไม่มีการเก็บเสียงของผู้เรียน (เสียงถูกแปลงเป็นข้อความโดยเบราว์เซอร์) ข้อมูลใน Sheet เปิดดูได้เฉพาะเจ้าของ Sheet ส่วนหน้ารายงานต้องใช้รหัสครู

## เว็บแฟ้มสะสมผลงาน (Portfolio)

หน้าเว็บเก็บผลงานทางวิชาการของ นางสาวศิริลักษณ์ ผาเนตร์ อยู่ในโฟลเดอร์ [`public/portfolio/`](public/portfolio/) และขึ้นเว็บพร้อมแอปนี้ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/portfolio/`

- **เพิ่ม/แก้ผลงาน**: แก้ไฟล์ [`public/portfolio/works.js`](public/portfolio/works.js) ไฟล์เดียว (ข้อมูลส่วนตัว หมวดหมู่ และรายการผลงาน แต่ละชิ้นใส่ลิงก์ Google Drive/PDF/YouTube และรูปปกได้) ผลงานที่ใส่ `sample: true` จะมีป้าย "ตัวอย่าง" ให้แทนด้วยผลงานจริง
- **สถิติการเข้าใช้งาน**: นับการเข้าชมทั้งหมด จำนวนผู้เข้าชม วันนี้ 7 วันล่าสุด กราฟรายวัน 14 วัน และจำนวนครั้งที่เปิดดูผลงานแต่ละชิ้น โดยใช้ Apps Script ตัวเดียวกับข้างบน (`?action=hit|view|stats` ไม่ต้องใช้รหัสครู) เก็บตัวเลขไว้ใน Script Properties หลังอัปเดต `Code.gs` ต้องสร้าง **เวอร์ชันใหม่** ของการทำให้ใช้งานได้ ถ้ายังเชื่อมไม่ได้ หน้าเว็บจะนับเฉพาะบนเครื่องผู้เข้าชมและแจ้งไว้ใต้กราฟ URL ของสคริปต์อยู่ใน [`public/portfolio/config.js`](public/portfolio/config.js)

## รันบนเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิดเซิร์ฟเวอร์สำหรับพัฒนาที่ http://localhost:5173
npm test           # รันเทสต์
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist/
```

## นำขึ้นเว็บ (GitHub Pages)

repo นี้มี workflow `.github/workflows/deploy.yml` ที่จะตรวจข้อมูล รันเทสต์ และ deploy ให้อัตโนมัติทุกครั้งที่ push เข้า branch `main`

1. ไปที่ **Settings → Pages** ของ repo
2. ตรงหัวข้อ **Source** ให้เลือก **GitHub Actions**
3. merge โค้ดเข้า `main` เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ไฟล์ใน `dist/` เป็นไฟล์ static ทั้งหมด จึงนำไปวางบนโฮสติ้งอื่นได้ด้วย เช่น Netlify หรือ Vercel

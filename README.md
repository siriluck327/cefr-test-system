# ศัพท์ 5000: เว็บแอปเรียนคำศัพท์ภาษาอังกฤษตามระดับ CEFR

เว็บแอปสำหรับเรียนคำศัพท์ภาษาอังกฤษ 5,000 คำ แบ่งเป็น 5 ระดับ (A1–C1) มีแฟลชการ์ดที่ใช้ระบบทบทวนเป็นระยะ (spaced repetition) และแบบทดสอบความหมายภาษาไทย ความก้าวหน้าทั้งหมดบันทึกไว้ในเบราว์เซอร์ของผู้เรียน ไม่ต้องล็อกอิน และไม่มีเซิร์ฟเวอร์

## คุณสมบัติ

- **แฟลชการ์ด**: แตะการ์ดเพื่อดูความหมาย แล้วเลือกว่า "ยังไม่จำ / จำได้ / ง่ายมาก" ระบบจะกำหนดวันทบทวนครั้งต่อไปให้เอง (ทบทวนเร็วขึ้นถ้าลืม และเว้นนานขึ้นถ้าจำได้)
- **แบบทดสอบ 4 ตัวเลือก**: ทำได้ทั้งแบบอังกฤษ→ไทย และไทย→อังกฤษ เลือกจำนวน 10–50 ข้อ และเลือกคำจากทั้งระดับ จากคำที่เรียนแล้ว หรือจากคำที่ยังจำไม่แม่น คำที่ตอบผิดจะกลับมาให้ทบทวนในแฟลชการ์ด
- **ฟังเสียงอ่าน**: ใช้เสียงสังเคราะห์ของเบราว์เซอร์ (Web Speech API) จึงไม่ต้องใช้ไฟล์เสียง
- **รายการคำและค้นหา**: ค้นหาได้ทั้งคำอังกฤษและคำไทย และกรองตามสถานะการเรียน
- **สถิติ**: ความก้าวหน้าแต่ละระดับ จำนวนวันที่เรียนติดต่อกัน และผลแบบทดสอบย้อนหลัง
- **สำรองและนำเข้าข้อมูล**: ดาวน์โหลดความก้าวหน้าเป็นไฟล์ JSON เพื่อย้ายไปเครื่องอื่นได้
- ใช้บนมือถือได้ รองรับโหมดมืด และมีคีย์ลัดบนคอมพิวเตอร์ (Space = พลิกการ์ด, 1/2/3 = ให้คะแนน, 1–4 = เลือกคำตอบ, Enter = ข้อต่อไป, S = ฟังเสียง)

## ที่มาของคำศัพท์

| ระดับ | จำนวนคำ | ที่มา |
|---|---:|---|
| A1 | 898 | The Oxford 3000™ by CEFR level |
| A2 | 867 | The Oxford 3000™ by CEFR level |
| B1 | 806 | The Oxford 3000™ by CEFR level |
| B2 | 726 | The Oxford 3000™ by CEFR level |
| C1 | 1,703 | คัดเลือกเพิ่มเติม (คำศัพท์ระดับสูง/วิชาการ) |
| **รวม** | **5,000** | |

- บางคำอยู่ในหลายระดับเพราะมีความหมายหรือชนิดคำต่างกัน เช่น *like* (A1: ชอบ, เหมือน; B1: สิ่งที่ชอบ) ในข้อมูลนี้ถือเป็นการ์ดแยกกัน
- ความหมายภาษาไทยทั้งหมดเขียนขึ้นใหม่สำหรับแอปนี้ **ควรให้ครูตรวจทานก่อนนำไปใช้สอนจริง** โดยเฉพาะระดับ B2–C1
- ระดับของคำ C1 เป็นการประเมินของผู้จัดทำ ไม่ได้มาจากรายการทางการของ Oxford

## แก้ไขหรือเพิ่มคำศัพท์

คำศัพท์ทั้งหมดอยู่ในไฟล์เดียวคือ [`data/words.tsv`](data/words.tsv) ซึ่งเปิดแก้ใน Excel หรือ Google Sheets ได้ แต่ละบรรทัดมี 4 คอลัมน์ คั่นด้วย Tab:

```
level	word	pos	thai
A1	apple	n.	แอปเปิล
```

แก้ไขเสร็จแล้วตรวจความถูกต้องด้วยคำสั่ง `npm run check-data`

ความก้าวหน้าของผู้เรียนผูกกับ `ระดับ:คำ` ดังนั้นการแก้ความหมายจะไม่ทำให้ความก้าวหน้าหาย แต่ถ้าเปลี่ยนตัวสะกดของคำหรือย้ายคำไปอยู่ระดับอื่น ความก้าวหน้าของคำนั้นจะเริ่มใหม่

## รันบนเครื่อง

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install
npm run dev        # เปิดเซิร์ฟเวอร์สำหรับพัฒนาที่ http://localhost:5173
npm test           # รันเทสต์
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บไว้ในโฟลเดอร์ dist/
```

## นำขึ้นเว็บ (GitHub Pages)

repo นี้มี workflow `.github/workflows/deploy.yml` ที่จะตรวจข้อมูล รันเทสต์ และ deploy ให้อัตโนมัติทุกครั้งที่ push เข้า branch `main`

1. ไปที่ **Settings → Pages** ของ repo
2. ตรงหัวข้อ **Source** ให้เลือก **GitHub Actions**
3. merge โค้ดเข้า `main` เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ไฟล์ใน `dist/` เป็นไฟล์ static ทั้งหมด จึงนำไปวางบนโฮสติ้งอื่นได้ด้วย เช่น Netlify หรือ Vercel

## โครงสร้างโปรเจกต์

```
src/lib/srs.ts          ระบบทบทวนเป็นระยะ (Leitner 6 กล่อง)
src/lib/quiz.ts         สร้างคำถาม 4 ตัวเลือก

src/components/         หน้าจอต่างๆ (หน้าแรก แฟลชการ์ด แบบทดสอบ รายการคำ สถิติ)
tests/                  เทสต์ (Vitest)
```
